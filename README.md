# Stellar Odyssey

Stellar Odyssey is a visually stunning 3D Web3 game built for the Stellar Hackathon. It demonstrates the power and speed of the Soroban smart contract platform by allowing players to seamlessly trade in-game resources (fuel, materials) across a 3D galaxy using the Freighter wallet.

## Features
- **Immersive 3D Experience:** Built with React Three Fiber, featuring bloom effects, dynamic lighting, and orbital mechanics.
- **Soroban Powered:** Real-time simulated trading powered by Stellar's next-gen smart contract platform.
- **Freighter Wallet Integration:** Seamless login and transaction signing directly from the browser.

## Getting Started
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Make sure you have the [Freighter Wallet Extension](https://freighter.app/) installed in your browser.
